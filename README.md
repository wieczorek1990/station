# Station

`Station` is a new version of my dotfiles.

The idea behind the project is to build as much a possible for the working station.

## Installing.

```sh
git clone git@bitbucket.org:soiree-tech/station.git && cd station && make install && cd - >/dev/null
```

## Usage.

```sh
cd ~/Software/station/ && su administrator -c "sudo ./bin/up.sh"
```
